# Читалка на Banana pi (Banana_reader)

Своя кастомная читалка на Banana pi (с wifi) с цветным дисплеем и кастомным UI
Тут будут представлены все шаги для сбора:
1) обоснование элементной базы + список с ссылками на компоненты с алика
2) принципиалка 
3) электрическая схема
4) плата
5) схема корпуса для 3д печати 
6) ограничения
