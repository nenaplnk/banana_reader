# Читалка на Banana pi (Banana_reader)

Своя кастомная читалка на Banana pi (с wifi) с цветным дисплеем и кастомным UI
Тут будут представлены все шаги для сбора:
1) обоснование элементной базы
2) список с ссылками на компоненты с алика
3) принципиалка 
4) электрическая схема
5) плата
6) схема корпуса для 3д печати 
7) ограничения
